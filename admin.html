처음 한 번만: 저장 권한 연결

사진을 올리고 저장하려면 GitHub 토큰이 필요합니다. 이 기기 브라우저에만 저장되고 다른 곳으로 보내지 않습니다.

  1. GitHub 토큰 만들기를 엽니다.
  2. Token name: 아무 이름(예: 입원실 사진 관리), Expiration: 원하는 기간
  3. Resource owner: noble-i, Repository access: Only select repositories → homepage-hasegi
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate token을 누르고 나온 값을 아래에 붙여 넣습니다.
