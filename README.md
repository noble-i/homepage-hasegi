# 노블아이경희한의원 입원실 홈페이지

교통사고 입원과 1인실·가족실을 강조하는 부가 홈페이지입니다. 서버나 별도 프로그램 없이 파일만으로 동작합니다.

## 바로 보기

`index.html` 을 더블클릭하면 브라우저에서 열립니다.

## 내용 수정 방법

**`content.js` 파일 하나만 고치면 됩니다.** 메모장이나 VS Code로 열어 따옴표 안의 글자를 바꾸고 저장한 뒤, 브라우저에서 새로고침하세요.

| 바꾸고 싶은 것 | content.js 에서 찾을 곳 |
|---|---|
| 전화번호, 카톡·네이버 예약 주소 | `contact` |
| 진료시간 | `hours` |
| 첫 화면 문구와 사진 | `hero` |
| 병실 종류, 사진, 특징 | `rooms.items` |
| 자동차보험 안내 문구 | `insurance.auto` |
| 건강보험 입원 안내 켜기 | `insurance.health.enabled` 를 `true` 로 |
| 사진 갤러리 | `gallery.items` |
| 자주 묻는 질문 | `faq.items` |
| 원장 소개 | `doctor` |
| 주소, 주차, 교통편 | `location` |
| 사업자등록번호 | `footer.businessNumber` |

### 사진 바꾸기

1. 사진을 `images` 폴더에 넣습니다. 가로 1600px 정도, 파일 1장당 300KB 이하가 좋습니다.
2. `content.js` 에서 해당 항목의 파일명을 바꿉니다. 예: `"images/room-single-01.jpg"` → `"images/새사진.jpg"`

### 항목 추가·삭제

- 목록(`[ ... ]`) 안의 `{ ... },` 한 묶음이 항목 하나입니다. 복사해서 붙이면 추가, 지우면 삭제입니다.
- 마지막 항목 뒤에는 쉼표가 없어야 합니다. 쉼표가 어긋나면 화면이 비어 보입니다. 그럴 때는 마지막에 고친 곳의 쉼표를 확인하세요.

### 색상 바꾸기

`assets/style.css` 맨 위 `:root` 의 `--green`, `--gold` 값을 바꾸면 사이트 전체 색이 바뀝니다.

## 폴더 구성

```
noble-i-inpatient/
├─ index.html        화면 뼈대 (보통 손대지 않음)
├─ content.js        ★ 모든 글과 사진 목록 (여기만 수정)
├─ assets/
│  ├─ style.css      디자인
│  ├─ app.js         content.js 를 읽어 화면을 채우는 스크립트
│  └─ favicon.svg    브라우저 탭 아이콘
├─ images/           사진
└─ README.md         이 안내문
```

## 인터넷에 올리기

폴더 전체를 그대로 올리면 됩니다. 데이터베이스나 서버 설정이 필요 없습니다.

- **Netlify / Vercel / Cloudflare Pages**: 폴더를 끌어다 놓으면 무료로 주소가 생깁니다. 보유한 도메인을 연결할 수 있습니다.
- **카페24·가비아 등 웹호스팅**: FTP로 폴더 내용을 `public_html` 등 루트에 업로드합니다.
- 본원 사이트(noble-i.com)의 하위 주소(예: `noble-i.com/inpatient`)로 두고 싶다면, 본원 프로젝트의 `public` 폴더에 이 폴더를 넣는 방식도 가능합니다.

## 참고

- 글 내용은 자바스크립트로 채워집니다. 구글은 문제없이 읽지만, 네이버 검색 노출을 더 신경 쓰려면 나중에 글을 HTML에 직접 박아 넣는 작업(프리렌더)을 하면 좋습니다.
- 의료광고에 해당할 수 있는 문구(비용, 효과)는 게시 전에 한 번 더 확인하세요.
